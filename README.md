# Poetry Collection Website

A personal poetry website created using HTML and CSS to showcase original poems in a clean and visually appealing format.

## Features

* Responsive design
* Elegant typography for poetry
* Dark aesthetic theme
* Mobile-friendly layout
* Original poetry collection

## Technologies Used

* HTML5
* CSS3

## Project Purpose

This project was created to combine creative writing with web development. It serves as a digital space for sharing original poems while practicing front-end design skills.
